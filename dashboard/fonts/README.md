# Google Sans

Source: https://fonts.google.com/specimen/Google+Sans

License: SIL Open Font License 1.1, included in OFL.txt.

Locally hosted normal weights: 400, 500, 600, 700. WOFF2 files include Latin characters, punctuation, currency symbols, arrows, mathematical symbols, and geometric shapes. Other scripts use the CSS fallback font.

The files were downloaded from the Google Fonts CSS API and subset with fontTools. No external font requests are needed at runtime.
