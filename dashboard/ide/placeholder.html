Reprise IDE

The Reprise extension is published at __EXT_URL__. Until the rebranded web IDE build is enabled here, use it in Visual Studio Code for the Web:

  1. Open vscode.dev in Google Chrome or Microsoft Edge on desktop.
  2. Run Developer: Install Extension from Location… and enter __EXT_URL__.
  3. Open your repository clone with File → Open Folder, then Reprise: Sign In to GitHub and Reprise: Connect Runner.
